== Opis ==
Wtyczka raportuje podejrzane próby dostępu do serwisu do AbuseIPDB oraz blokuje adres IP po przekroczeniu progu (domyślnie 10 prób w 30 minut).

== Uwaga ==
- Raportowanie wymaga API Key z AbuseIPDB.
- Wtyczka ogranicza spam: maks 1 raport na IP na 12 godzin.
